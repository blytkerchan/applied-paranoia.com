To build the site, you need a recent version of Ruby, and a recent version of Bundle installed within that. Assuming you have that (if you don't check out jekyll.org to see how to set up), do the following after cloning to set up the site. Note that the rubygems site doesn't work with IPv6, but advertises that it does, so you need to disable IPv6 for this to work.

```
bundle install
```

While developing the site, you can serve it locally with 
```
bundle exec jekyll serve
```

Once done, you can build it with 
```
bundle exec jekyll build
```

To deploy, we use Serverless, which needs node.js. 

Before you can use this, the domain name needs to be registered with Route53 as a hosted zone. Serverless can't do that. (This is currently done).

To set up once you've cloned:
1. install nvm
```
nvm install 12
npm install -g serverless
serverless plugin install -n serverless-s3-sync
```

Now, to deploy, you need the keys to the AWS serverless user. You can create new ones if they're not already there in the AWS console, under IAM, and add them to your .bashrc:
```
export AWS_ACCESS_KEY_ID=xxxxxxxxxxxxxxxxxxxx
export AWS_SECRET_ACCESS_KEY=xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
```

Once that's done, you can do
```
bundle exec jekyll build
serverless deploy -v -s prod
```
to deploy the website to prod (vlinder.ca).
To deploy to dev, use `serverless deploy -v`, (to dev.vlinder.ca)

The deployed files are the ones generated by the Jekyll build. Change anything in the first, deploy again and the site will update.
